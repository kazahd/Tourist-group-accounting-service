# Сервис учета туристических групп

## Назначение
Приложение для проверки возможности добавления новых участников в туристическую группу. Решает задачу быстрой проверки наличия свободных мест и соответствия возраста участника перед добавлением в группу.

## Целевая аудитория
Организаторы туристических походов, руководители туристических клубов, волонтеры, занимающиеся организацией групповых путешествий.

## Предметная область
Управление туристическими группами и участниками. Приложение позволяет проверить, может ли новый участник присоединиться к группе, учитывая текущую заполненность группы и возрастные ограничения. В дальнейшем предполагается расширение функционала для полного учета всех аспектов организации походов.

## Основные сущности
- **Группа** - туристическая группа с определенным маршрутом и максимальной вместимостью
- **Участник** - человек, желающий присоединиться к группе (имя, возраст)
- **Поездка** - запланированное мероприятие с указанием даты проведения
- **Маршрут** - географическое направление похода (локация, сложность)

## Основные функции
- Проверка возможности добавления участника в группу (наличие свободных мест)
- Проверка возраста участника на соответствие требованиям
- Отображение текущего статуса группы (количество участников, свободные места)
- Информирование о дате и маршруте предстоящей поездки

## План развития

На следующих этапах планируется:

- разработка веб-приложения на Django с интерфейсом для управления группами;
- подключение базы данных для хранения информации о группах, участниках и поездках;
- реализация пользователей с разными ролями (организатор, участник);
- разработка REST API для интеграции с другими сервисами;
- контейнеризация приложения с помощью Docker;
- настройка CI/CD для автоматического тестирования и деплоя.
