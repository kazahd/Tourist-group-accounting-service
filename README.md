# Сервис учета туристических групп

Консольное приложение для учета туристических групп и их участников.

## Возможности

- просмотр и поиск групп;
- добавление групп;
- просмотр и добавление участников;
- проверка возраста участника;
- фильтрация участников по возрасту;
- сохранение данных в JSON-файлах.

## Структура проекта

- `main.py` — точка запуска, меню приложения;
- `groups.py` — работа с группами;
- `participants.py` — работа с участниками;
- `storage.py` — сохранение и загрузка данных;
- `utils.py` — ввод с обработкой ошибок;
- `data/` — JSON-файлы данных;
- `tests/` — автоматизированные тесты.

## Требования

- Python 3.x;
- pytest;
- flake8.

Установка зависимостей:

    pip install -r requirements.txt

## Запуск программы

    python main.py

## Запуск тестов

    python -m pytest

## Проверка качества кода

    python -m flake8

## План развития

На следующих этапах планируется:

- разработка веб-приложения на Django с интерфейсом для управления группами;
- подключение базы данных для хранения информации о группах, участниках и поездках;
- реализация пользователей с разными ролями (организатор, участник);
- разработка REST API для интеграции с другими сервисами;
- контейнеризация приложения с помощью Docker;
- настройка CI/CD для автоматического тестирования и деплоя
