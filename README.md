# Сервис учета туристических групп

Консольное приложение для учета туристических групп и их участников.

## Возможности

- просмотр, поиск и добавление групп;
- просмотр и добавление участников;
- фильтрация участников по возрасту;
- просмотр и добавление поездок;
- сохранение данных в JSON-файлах.

## Основные классы

### Group

Туристическая группа.

- **Атрибуты:** `id`, `name`, `route`, `max_capacity`
- **Методы:**
  - `has_free_places(current_members)` — есть ли свободные места;
  - `__str__()` — строковое представление.

### Participant

Участник группы.

- **Атрибуты:** `id`, `name`, `age`
- **Методы:**
  - `is_adult()` — совершеннолетний ли участник;
  - `__str__()` — строковое представление.

### Trip

Поездка группы.

- **Атрибуты:** `id`, `group` (объект `Group`), `trip_date`
- **Методы:**
  - `__str__()` — строковое представление.

## Взаимодействие объектов

Объект `Trip` хранит ссылку на объект `Group`, что позволяет получать данные группы напрямую: `trip.group.name`.

## Структура проекта

- `main.py` — точка запуска, меню;
- `storage.py` — сохранение и загрузка JSON;
- `utils.py` — ввод с обработкой ошибок;
- `models/` — классы предметной области:
  - `groups.py` — `Group` и функции;
  - `participants.py` — `Participant` и функции;
  - `trips.py` — `Trip` и функции;
- `data/` — JSON-файлы данных;
- `tests/` — автоматизированные тесты.

## Требования

- Python 3.x;
- pytest;
- flake8.
