# Сервис учета туристических групп

Приложение для управления туристическими группами, участниками и поездками. Включает консольную версию и веб-интерфейс на базе фреймворка Django.

## Назначение

Сервис позволяет вести учет туристических групп, добавлять участников, проверять возрастные ограничения, планировать поездки и просматривать информацию через веб-браузер.

Приложение позволяет:
* просматривать и добавлять группы;
* просматривать и добавлять участников;
* привязывать участников к группам;
* фильтровать участников по возрасту;
* просматривать и добавлять поездки;
* просматривать данные в веб-интерфейсе.

## Используемые технологии

* Python 3;
* Django 5.2 — веб-фреймворк (ПР5);
* HTML — разметка веб-страниц;
* CSS и Bootstrap 5.3 — оформление страниц;
* JSON — хранение данных (на текущем этапе);
* pytest — автоматизированные тесты;
* flake8 — проверка качества кода.

## Целевая аудитория

Организаторы походов, туристические клубы и руководители групп, которым необходимо вести учет участников и планировать поездки.

## Предметная область

Управление туристическими группами и поездками.
* Группа имеет название, маршрут и максимальную вместимость.
* Участник характеризуется именем и возрастом.
* Поездка привязана к определенной группе и имеет дату.
* Взаимодействие: поездка (Trip) связана с группой (Group), участник (Participant) может быть привязан к группе.

## Основные сущности (классы)

### Group — туристическая группа
* **Атрибуты:** `id`, `name` (название), `route` (маршрут), `max_capacity` (вместимость).
* **Методы:** `has_free_places()`, `__str__()`.

### Participant — участник
* **Атрибуты:** `id`, `name` (имя), `age` (возраст), `group` (объект группы).
* **Методы:** `is_adult()`, `__str__()`.

### Trip — поездка
* **Атрибуты:** `id`, `group` (объект группы), `trip_date` (дата).
* **Методы:** `__str__()`.

## Веб-интерфейс (Django)

Веб-версия реализована в ПР5. Она использует классы и функции, созданные в ПР3, и загружает данные из JSON-файлов.

### Страницы и URL
* `/` — главная страница (view-функция `index`);
* `/groups/` — список групп (view-функция `groups`);
* `/groups/<int:group_id>/` — карточка конкретной группы (view-функция `group_detail`);
* `/trips/` — список поездок (view-функция `trips`);
* `/trips/<int:trip_id>/` — карточка конкретной поездки (view-функция `trip_detail`).
* Настроена кастомная обработка ошибки 404 (`page_not_found`).

### Оформление
Используется фреймворк Bootstrap 5.3 (подключен через CDN). Внедрен общий HTML-каркас `page()` с навигационным меню для единообразия страниц.
